# Data Engineering Challenges Repository

This repository contains a collection of challenges and exercises for data engineering practice. The challenges are organized by topic, allowing you to focus on specific skills and technologies commonly used in data engineering.

## Repository Structure

The repository is organized into directories by topic:

- **sql/**: SQL-related challenges
  - **basic/**: Fundamental SQL concepts
    - **aggregations/**: Challenges focused on data aggregation techniques
  - (More SQL topics will be added)
- (More topics will be added, such as Python, Spark, Airflow, etc.)

## Available Challenges

### SQL Challenges

#### Basic Aggregations
- **Challenge 1**: Basic aggregation using GROUP BY clauses
- **Challenge 2**: Advanced aggregation using window functions

## How to Use This Repository

Each challenge directory contains:
- A README with challenge descriptions
- Setup instructions for the required environment
- Sample data and initialization scripts
- Solution files (try to solve the challenges yourself before looking at these!)

## Getting Started

1. Clone this repository
2. Navigate to the challenge directory you want to work on
3. Follow the setup instructions in the challenge's README
4. Solve the challenges and compare with the provided solutions
